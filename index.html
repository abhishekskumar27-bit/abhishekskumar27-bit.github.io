Secure Keyword Search over Dual-Server Encrypted Data

Java, MySQL, HTML, CSS | Aug 2025 to Mar 2026

A privacy-preserving search system (EncryptoSearch) that lets users search encrypted cloud files by keyword without exposing file contents or what they searched for.

  • Dual-server design (Assistant Server and Test Server) that splits trust to resist insider keyword guessing attacks.
  • Trapdoor-based query generation with authenticated access, so only authorized users can search.
  • Reviewed 5 research papers and compared the design against single-server approaches.
How it works

The data owner encrypts files and embeds searchable keywords. An authorized receiver creates a trapdoor, the Assistant Server turns it into intermediate ciphertexts, and the Test Server checks the match and returns only verified encrypted results.
